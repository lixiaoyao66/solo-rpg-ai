# 单人AI跑团网站

> AI驱动的单人DND跑团平台，支持长战役，视觉丰富，低门槛

## 📋 项目简介

这是一个基于AI的单人TRPG（桌上角色扮演游戏）平台，让玩家可以随时随地体验DND（龙与地下城）的冒险乐趣。

### 核心特性

- 🎲 **规则完整**：完整的DND 5e规则支持，AI判断检定
- 🎨 **视觉丰富**：AI生成场景图、角色立绘，预设怪物/NPC素材
- 🧠 **AI记忆**：三层记忆系统，支持长战役
- ⚔️ **战斗系统**：回合制战斗，先攻追踪，动作经济
- 💾 **存档系统**：支持长战役的存档/读档
- 🎯 **双模交互**：打字自由输入 + 点击选项

## 🛠️ 技术栈

### 前端
- Next.js 14 + TypeScript
- Tailwind CSS + shadcn/ui
- Zustand（状态管理）

### 后端
- FastAPI + Python 3.11+
- Pydantic v2（数据校验）
- SQLAlchemy 2.0（ORM）

### 数据库
- Supabase（PostgreSQL + Auth + Storage）

### AI
- Claude API（核心叙事）
- OpenAI API（辅助）
- DALL-E 3（图片生成）

## 🎮 视觉风格

- **界面框架**：明亮卡通风（易用性）
- **游戏内容区**：暗黑奇幻（沉浸感）
- **配色方案**：经典奇幻 + 暖色羊皮纸
- **参考产品**：博德之门3、神界原罪

## 🚀 开发计划

### Phase 1: MVP（第1-2个月）
- 用户注册/登录
- 角色创建（自建 + 随机）
- 基础游戏循环（AI对话 + 掷骰）
- 存档/读档
- 角色状态追踪

### Phase 2: 视觉系统（第3-4个月）
- 场景图生成（AI）
- 角色立绘（AI生成 + 上传）
- 怪物/NPC立绘（预设库）
- 骰子动画优化
- UI美化

### Phase 3: 战斗系统（第5-6个月）
- 先攻系统
- 动作经济追踪
- 状态效果追踪
- 战斗地图（网格）
- 怪物AI决策

### Phase 4: AI记忆系统（第7-8个月）
- 三层记忆系统
- 战役摘要生成
- 世界状态追踪
- NPC关系系统

- 成就系统
- 排行榜
- COC规则支持
